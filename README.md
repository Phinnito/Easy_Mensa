# Easy_Mensa 🐱

这是“小猫食堂 / Easy_Mensa”的私人菜谱项目。

目标是让不会做饭的人也能根据现有食材、难度和使用场景轻松找到可以做的菜；黄师傅端则提供可视化菜谱录入和维护。

## 当前第一版

### 👨‍🍳 黄师傅后台
- 可视化新增菜谱
- 菜系分类
- 聚会菜谱 / 精致一人食 / 随便吃点 / 两个人吃 / 认真做饭
- 制作难度、食材复杂度、分享度
- 食材分为：必须有 / 最好有 / 有更好
- 每种食材可以添加替换食材
- 替换程度分为：
  - 基本没问题
  - 味道会有一点区别
  - 味道会明显变化
- 已经出现过的原始食材和替换食材会自动进入后续候选列表
- 在 Codespaces 中保存菜谱后会尝试自动 commit + push 到 GitHub

### 🐱 小猫食堂
- 浏览全部菜谱
- 按菜系、难度、时间、分享度等查看
- “我有什么”食材选择
- 自动判断：
  - 很适合做
  - 可以做
  - 可以用替代食材做
  - 可以做但味道会变化
  - 缺少必要食材

## 推荐开发方式：GitHub Codespaces

在 GitHub 仓库页面：

1. 点击 **Code**
2. 打开 **Codespaces**
3. 点击 **Create codespace on main**
4. 第一次启动时会自动安装 Python 依赖

### 打开黄师傅后台

```bash
bash admin.sh
```

### 打开小猫食堂

先停止当前 Streamlit（Terminal 中 Ctrl+C），然后：

```bash
bash xiaomao.sh
```

Codespaces 会自动转发 8501 端口并提供浏览器页面。

## 数据位置

每道菜一个 JSON：

```text
data/recipes/
```

菜品图片：

```text
images/recipes/
```

程序会扫描所有菜谱中的主食材与替代食材，从而自动形成智能食材候选库。
